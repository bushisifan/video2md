# video2md 安装部署指南

> 本文档面向**自动化 Agent 或运维人员**：按顺序执行即可在 **macOS 或 Windows** 上完成
> video2md 的完整部署并跑通端到端流程。文中"实测"数据来自 16GB 内存 / 10 核 M 系列
> Mac（CPU 推理，无 GPU 加速），Windows 命令已按原生环境编写，未在 Windows 实机复测。

---

## 0. 部署拓扑与资源要求（先读这里）

video2md 需要三类模型，**其中两类本地、一类可选云端**：

| 组件 | 作用 | 部署形态 | 本地内存峰值（实测） |
|---|---|---|---|
| **ASR**（FunASR paraformer-zh + fsmn-vad + ct-punc-c） | 中文转写 + 逐句时间戳 | 本地，**CPU** | **约 3.5 GB** |
| **视觉理解**（Qwen2.5-VL，经 Ollama / vLLM） | 读截图推断操作 | 本地，CPU 或 GPU | **约 4.5 GB**（qwen2.5vl:3b 常驻） |
| **步骤合成**（LLM） | 合并信号生成 SOP 步骤树 | 云端 API（如 DeepSeek）**或** 本地 vLLM | 云端约 0；本地另加模型内存 |

> **结论：16GB 内存机型勉强可跑（本指南默认配置）；8GB 机型必须改用更小视觉模型或把
> 视觉/合成挪到云端。运行前请关闭 Chrome/Safari/IDE 等大内存应用，否则会触发 swap
> 导致 ASR 停滞数十分钟。** 详细数据见第 8 节。

### 最低 / 推荐配置

| | 最低（可跑，慢） | 推荐（本指南配置） |
|---|---|---|
| 内存 | 12 GB | **16 GB+** |
| CPU | 4 核 | 8 核+ |
| 磁盘 | 8 GB 空闲 | 20 GB 空闲（模型约 5.3 GB） |
| GPU | 无（CPU 推理） | 有则视觉提速 10×+ |
| 系统 | macOS 12+ / Windows 10+ | 同左 |
| Python | 3.10+（实测 3.12） | 3.12 |

## 1. 前置依赖安装

### 1.1 Python 3.10+

**macOS**

```bash
brew install python@3.12
python3 --version   # 应输出 Python 3.12.x
```

**Windows**（二选一）

```powershell
winget install Python.Python.3.12
# 或从 https://www.python.org/downloads/ 下载安装包，勾选 "Add Python to PATH"
python --version
```

### 1.2 ffmpeg

**macOS**

```bash
brew install ffmpeg
ffmpeg -version | head -1
```

**Windows**

```powershell
winget install Gyan.FFmpeg
# 或 https://ffmpeg.org/download.html 下载，把 bin 目录加入 PATH
ffmpeg -version
```

### 1.3 pandoc（可选，用于 `--export pdf/docx/html`）

**macOS**：`brew install pandoc`
**Windows**：`winget install JohnMacFarlane.Pandoc`

不用 `--export` 可以跳过。

## 2. 拉取代码并创建虚拟环境

```bash
git clone https://github.com/bushisifan/video2md.git
cd video2md

python3 -m venv .venv
```

**macOS / Linux 激活：**

```bash
source .venv/bin/activate
```

**Windows 激活：**

```powershell
.venv\Scripts\activate
```

> 激活后命令行前缀应出现 `(.venv)`。后续所有 `pip` / `video2md` 命令都在此环境内执行。

## 3. 安装 Python 依赖

### 3.1 安装包本体（含 openai / pydantic / opencv / yaml）

```bash
pip install -e .
```

### 3.2 安装 ASR 运行库（torch + torchaudio + funasr + modelscope）

> ⚠️ **必须先装 torch，再装 funasr**，否则 funasr 会拉一个很大的默认 torch。

**macOS（Apple Silicon 走 Metal / Intel 走 CPU）**

```bash
pip install torch torchaudio
pip install funasr modelscope
```

**Windows · CPU**

```bash
pip install torch torchaudio --index-url https://download.pytorch.org/whl/cpu
pip install funasr modelscope
```

**Windows · 有 NVIDIA 显卡（CUDA 加速）**

```bash
pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu126
pip install funasr modelscope
```

> 首次运行 ASR 时 FunASR 会从 ModelScope 自动下载 3 个模型（paraformer ~953MB +
> fsmn-vad ~4MB + ct-punc-c ~283MB，合计约 1.3 GB，见 8.4 节）。若把 `asr.model` 改为
> `iic/SenseVoiceSmall` 则额外下载 ~897MB。
> 如需完全离线部署，可预先在其他机器下载后拷贝到 `~/.cache/modelscope/models/`。

### 3.3 验证安装

```bash
python -c "import funasr, torch, cv2, pydantic, openai, yaml; print('deps ok, torch', torch.__version__)"
```

## 4. 部署视觉模型（Ollama + Qwen2.5-VL）

### 4.1 安装 Ollama

**macOS**

```bash
brew install ollama
```


```bash
# 启动服务（macOS 装 .app 后常驻；命令行方式：）
```

```bash

```

## 5. 配置（模型端点 + API Key）

默认配置在 `video2md/config.yaml`。**不要改它**——复制一份本地配置，把所有需要覆盖的
section 写进去，真实 API Key 也放这里（该文件已在 `.gitignore` 中，不会入库）。

```bash
cp video2md/config.yaml config.local.yaml
```

编辑 `config.local.yaml`，至少改成这样：

```yaml
vision:
  base_url: http://localhost:11434/v1      # Ollama 的 OpenAI 兼容端点
  api_key: EMPTY                            # Ollama 不需要真实 key
  model: qwen2.5vl:3b

compose:
  base_url: https://api.deepseek.com/v1     # 云端合成 LLM（OpenAI 兼容）
  api_key: sk-xxxxxxxxxxxxxx                # ← 你的 DeepSeek API Key
  model: deepseek-chat                      # 不要用推理模型（deepseek-reasoner），会超时/格式不稳
  temperature: 0.1
  max_tokens: 8192
```

> **不想要云端合成？** 把 `compose.base_url/model` 指向本地 vLLM（如
> `http://localhost:8000/v1` + `Qwen/Qwen2.5-7B-Instruct`），并给 `api_key` 填任意占位。
> 此时全链路 100% 本地。

> **合成 LLM 不要用推理模型**：步骤合成要求严格 JSON 输出（`response_format=json_object`），
> 推理模型（如 `deepseek-reasoner`）会拖慢甚至破坏输出格式。

## 6. 端到端验证

用一小段录屏快速验证（建议先用 1~3 分钟短视频，别一上来跑 1 小时）：

```bash
# 先从任意视频截 60 秒做冒烟测试（可选）
# ffmpeg -y -i 你的长视频.mp4 -t 60 -c copy /tmp/smoke.mp4

video2md /tmp/smoke.mp4 -o /tmp/sop_test -c config.local.yaml
```

```
[extract_frames] 0/1

  Mermaid:   /tmp/sop_test/flowchart.mmd
  关键帧: 3, 转写片段: 40, 步骤时间窗: 3, 视觉理解: 3, 点击事件: 0
```

**检查产物：**

```bash
ls /tmp/sop_test/            # 应有 SOP.md flowchart.mmd audio.wav images/
ls /tmp/sop_test/images/     # frame_0001.png ...
```

**正确性抽查（人工/Agent 验证）：**

- `SOP.md` 开头是 `# 标题` + `## 文档信息` 表格。
- 每个 `### 步骤 N:` 下有一个 `![截图](images/frame_*.png)`，且该截图时间戳落在步骤时间窗内。
- `grep -c '^### 步骤 ' SOP.md` 与 `images/` 帧数一致（说明文图对齐）。
- `flowchart.mmd` 可被 Mermaid 解析（不含非法字符）。

> 换用 `--export pdf` 前先 `pip` 侧确认 pandoc 已装，见 1.3。

## 8. 运行时内存 / CPU 占用（重点）

> 以下为 **16GB / 10 核 M 系列 Mac · CPU 推理** 实测值。Windows 行为类似（torch 用
> CPU 则相近；用 CUDA 则内存压力转移到显存）。

### 8.1 各阶段占用

| 阶段 | 峰值内存 | CPU 行为 | 实测耗时 |
|---|---|---|---|
| **ASR**（FunASR） | **约 3.5 GB**（模型常驻，整段音频一次载入） | 多核计算，约 **27× 实时** | 模型加载 ~8s；16min 音频转写 ~40s |
| **抽帧**（ffmpeg + OpenCV） | < 1 GB | 秒级 | 秒~1 min（估算，视视频时长/分辨率） |
| **视觉理解**（Ollama qwen2.5vl:3b） | **约 4.5 GB**（模型常驻不释放） | 每帧全量前向 | **每帧约 6s**（768px PNG） |
| **步骤合成**（DeepSeek API） | 本地近 0 | 网络等待 | ~0.5–1 min（视 token 量） |
| **渲染** | < 0.5 GB | 秒级 | 秒级 |

**端到端实测：16 分钟录屏（17 步、17 帧、视觉 0 退化）全程约 3m23s。**

### 8.2 峰值内存怎么算

管线是**串行**的（见 `pipeline.py`），但 Ollama 模型加载后**常驻不释放**：

- ASR 阶段峰值 ≈ ASR 3.5GB + 系统基础 ≈ **5~6 GB**
- 视觉阶段峰值 ≈ Ollama 4.5GB + 系统基础 ≈ **5~6 GB**
- 若同时开着 Chrome/IDE → 轻松超过 16GB → **swap 陡增，ASR 会慢到停滞**

### 8.3 内存调优清单

| 场景 | 措施 |
|---|---|
| 16GB 机型 | 运行前关掉 Chrome/Safari/IDE/微信；必要时先释放后重启 |
| 8GB 机型 | 视觉换 `qwen2.5vl:1.5b`（~2GB）；或视觉/合成全走云端 API |
| 长视频（>30min） | 分块处理：`ffmpeg -i v.mp4 -t 1800 -c copy a.mp4` 等，再逐个跑 |
| 有 GPU | 视觉用 vLLM 或 Ollama（自动用 GPU），每帧 6s→亚秒，内存压到显存 |
| 想更小 ASR | ASR 峰值由 paraformer-large 决定，属最轻量本地项，不建议再降 |

### 8.4 磁盘占用

| 内容 | 大小 |
|---|---|
| FunASR 默认 3 个模型（paraformer 953MB + vad 4MB + punc 283MB） | 约 1.3 GB |
| Ollama qwen2.5vl:3b | 3.2 GB |
| 中间产物 audio.wav / images/ | 每视频数十 MB~几百 MB |

## 9. 故障排查

| 现象 | 原因 / 处理 |
|---|---|
| `Ollama ... 502 Bad Gateway`（视觉失败） | 系统代理（如 SakuraCat/Clash）拦截了 localhost 大图请求。video2md 客户端已设 `trust_env=False` 忽略系统代理，但若代理以 TUN/全局模式劫持流量，需在代理软件里放行 `localhost/127.0.0.1`。 |
| ASR 极慢 / 进程卡住几十分钟 | 内存不足触发 swap。按 8.3 关闭大内存应用后重跑。 |
| `pandoc not found` | 没装 pandoc，或没在 `--export` 前确认 `shutil.which("pandoc")`。装好并加入 PATH。 |
| 合成步骤提示词报 JSON 校验失败 | 确认 `compose.model` 是**非推理**模型（如 `deepseek-chat`），并检查 API Key 余额。 |
| 首次 ASR 卡在 `download models from model hub` | 网络下载约 1.3GB 模型（见 8.4）。国内网络可先在可联网机器用 `modelscope download --model iic/speech_seaco_paraformer_large_asr_nat-zh-cn-16k-common-vocab8404-pytorch` 预下载，再把整个 `~/.cache/modelscope/models/` 拷到目标机。 |
| `ffmpeg not found` | 见 1.2 安装并确认 `PATH`。 |

## 10. 一键脚本（可选）

**macOS `deploy.sh`：**

```bash
#!/usr/bin/env bash
set -euo pipefail
brew install ffmpeg ollama pandoc python@3.12
python3 -m venv .venv && source .venv/bin/activate
pip install -e .
pip install torch torchaudio funasr modelscope
ollama serve & ollama pull qwen2.5vl:3b
echo "完成。请按第 5 节创建 config.local.yaml"
```

**Windows `deploy.ps1`：**

```powershell
winget install Gyan.FFmpeg; winget install Ollama.Ollama; winget install JohnMacFarlane.Pandoc; winget install Python.Python.3.12
python -m venv .venv; .\.venv\Scripts\Activate.ps1
pip install -e .
pip install torch torchaudio --index-url https://download.pytorch.org/whl/cpu
pip install funasr modelscope
ollama pull qwen2.5vl:3b
Write-Host "完成。请按第 5 节创建 config.local.yaml"
```

> 跑脚本前请先阅读第 0 节确认机器内存足够。
